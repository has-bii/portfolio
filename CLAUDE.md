## Project

A personal portfolio single-page site (Hasbii). Client-side rendered React SPA built with Vite + TanStack Router (file-based routing, no SSR/server functions despite the boilerplate README mentioning TanStack Start — `main.tsx` mounts the app directly with `ReactDOM.createRoot`).

## Commands

```bash
pnpm dev       # start dev server on port 3000
pnpm build     # production build
pnpm preview   # preview production build
pnpm test      # run vitest (no test files exist yet)
pnpm lint      # eslint
pnpm format    # prettier --write . && eslint --fix
pnpm check     # prettier --check .
```

There is no single-test-file command configured; use `pnpm vitest run <path>` directly if needed.

## Architecture

- **Routing**: TanStack Router with file-based routes in `src/routes/`. `src/routeTree.gen.ts` is auto-generated by the `@tanstack/router-plugin` Vite plugin on dev/build — don't hand-edit it. `src/routes/__root.tsx` wraps every route in `ReactLenis` (smooth scrolling) and imports the global `src/styles.css`.
- **Entry/preload flow**: `src/main.tsx` renders a `Preloader` (`src/components/Preloader.tsx`) that waits on `preloadImages`/`preloadRouteChunks` from `src/data/preload.ts` before fading in the router via `motion`. Any change to preloaded assets should go through `src/data/preload.ts`.
- **Page composition**: The home page (`src/routes/index.tsx`) is a straight-line composition of section components from `src/components/home/` (`Hero`, `AboutMe`, `Services`, `SelectedWork`, `CTA`) separated by `<Separator />`, plus a global `Footer`. New sections follow this same pattern: a default-exported component in `src/components/home/`, dropped into `index.tsx`.
- **Content as data**: Copy/config that drives sections lives in `src/data/*.ts` (`projects.ts`, `services.ts`, `socials.ts`) as typed arrays/objects, kept separate from the components that render them.
- **UI primitives**: `src/components/ui/` holds shadcn-generated primitives (Radix-based, style `radix-vega`, base color `neutral`). Add new primitives via the shadcn CLI (`components.json` config) rather than hand-rolling; project uses `radix-ui` (unified package) + `class-variance-authority` + `tailwind-merge` (`cn()` helper in `src/lib/utils.ts`).
- **Styling**: Tailwind CSS v4 via `@tailwindcss/vite` (no `tailwind.config.js` — config lives in `src/styles.css`). `tw-animate-css` for animation utilities.
- **Animation**: `motion` (Framer Motion's successor package, imported as `motion/react`) is used throughout for transitions/entrance effects; see `Preloader.tsx` and `AboutMe.tsx` for the established idioms (`AnimatePresence`, opacity/blur transitions).
- **Path alias**: import app code with `@/...` (maps to `src/*`, configured in `tsconfig.json`). Note `package.json` also declares a `#/*` subpath import but the codebase consistently uses `@/*`.

## Conventions

- No semicolons, single quotes, trailing commas, 100-char print width (Prettier, enforced via `prettier-plugin-tailwindcss` which also sorts Tailwind classes).
- ESLint config extends `@tanstack/eslint-config` with `import/no-cycle`, `import/order`, `sort-imports`, and a few `@typescript-eslint` rules turned off (see `eslint.config.js`).
- TypeScript strict mode with `noUnusedLocals`/`noUnusedParameters` enforced.
